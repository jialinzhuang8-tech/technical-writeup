# 案例 B 任务（变化与复用；同一版本 Skill）

## 与 A 的实质差异
- 不同论文、不同方法族：Alvarez & Ferman (2023), *Extensions for Inference in Difference-in-Differences with Few Treated Clusters*, arXiv:2302.03131v1（`input/`）。这是一篇**推断(inference)理论笔记**，不含实证和仿真，主体是假设、估计量、命题与证明；而 A 是以仿真示例为主的实务性短文。
- 不同的用户问题与设定：处理组很少（几个省/几个城市），对照组很多；需要判断"我的聚类稳健标准误还可信吗？这篇论文给的替代方法适用吗？"

## 用户的决策问题
> 我做一个城市层面政策评估，只有 7 个处理城市，对照城市约 280 个，处理时点不同（交错）。我准备用"按城市聚类的标准误"并画事件研究图。这篇论文说我该怎么办？它的方法能直接用于我的数据吗？论文对"何时有效"设了哪些条件？

## 用户设定
- 处理单位数 N1=7（固定、很少），从未处理对照单位 N0≈280；
- 交错处理，估计事件研究（多个相对时间的参数）；
- 聚合到城市层面的面板数据；
- 缺项：未说明结果变量是否由个体数据聚合而来、各城市规模 Zi 是否可得；未说明是否使用 not-yet-treated 作控制。
