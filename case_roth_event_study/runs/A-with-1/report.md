# 阅读报告：默认 did 事件研究图处理前系数贴近 0，能否写“平行趋势得到验证、DID 设定有效”？

论文：Roth, *Interpreting Event-Studies from Recent Difference-in-Differences Methods*, arXiv:2401.12309v2（共 15 页，页码均为 PDF 页序；该 PDF 页脚打印页码与 PDF 页序一致）。

## 1. 一句话结论

**不能**这样写（有条件，强度：中等偏强）。默认 `did` 事件研究图的处理前、处理后系数构造不对称，论文显示“前平、后出现拐点”的图可以在没有处理效应、仅有平行趋势违反时出现（F6、F9）；处理前接近 0 只能写成“与平行趋势相容”，不是验证。论文建议用 `base_period="universal"` 重画，并补充分队列均值图、平衡样本图和敏感性分析（F1、F2、F16、F17、F20）。

## 3. 原文事实（均已由脚本逐字核验）

- **F1（p.10）** 作者对 CS 的修改方案：处理前系数也用长差分。
  > which is to use “long-differences” for the pre-treatment coefficients as well as the post-treatment coefficients
- **F2（p.10）** 实现选项。
  > This can be implemented, for example, in the did R and csdid Stata packages using the options base_period = “universal” and long2,
- **F3（p.10）** 数值等价只在非交错设定下成立。
  > Using these settings, the event-study estimates are numerically equivalent to the dynamic TWFE specification in the non-staggered setting considered here.
- **F4（p.7）** CS 默认构造不对称（common timing 推导）。
  > the pre-treatment coefficients are “short-differences”, i.e. comparisons of consecutive periods, whereas the post-treatment coefficients are “long-differences”
- **F5（p.5）** 论文的 CS 图用 R did 默认设置。
  > Panel (b) shows the results for the event-study generated by the CS method, using the default settings in the did package in R.
- **F6（p.3）** 模拟中 CS 默认图出现拐点。
  > the event-study plot produced by the R package for implementing the method of Callaway and Sant’Anna (2021, henceforth, CS) shows a clear kink at the treatment date.
- **F7（p.3）** 证据规模：单次模拟。
  > Figure 1 shows event-studies for a single simulation draw from this DGP when there are 100 total units and half of them are treated.
- **F8（p.3）** 模拟设定无处理效应（平行趋势被违反）。
  > There are no treatment effects in any period
- **F9（p.9）** 核心实践结论。
  > a kink or jump in the plot may arise even if there is no treatment effect and parallel trends is equally violated in all periods.
- **F10（p.9）** 不要套用 TWFE 的目视推断经验。
  > One should therefore not apply the typical heuristics for visual inference
- **F11（p.9）** 前后系数比较式敏感性分析可能误导。
  > Sensitivity analyses that compare the pre-treatment and post-treatment coefficients from these event-studies (e.g. Manski and Pepper, 2018; Rambachan and Roth, 2023) may likewise yield misleading conclusions given the asymmetric construction of the pre- and post-treatment coefficients.
- **F12（p.12）** 处理后估计的有效性本身不受威胁（前提：相应平行趋势成立）。
  > the discussion here does not threaten the validity of the post-treatment event-study estimates for recent methods if the appropriate parallel trends assumption holds
- **F13（p.2）** 事件研究图的第二个用途。
  > provide evidence about the validity of the research design
- **F14（p.12，脚注 14）** 应看预趋势系数的量级和置信区间。
  > researchers should ideally also look at the magnitudes of the pre-trends estimates and their confidence intervals.
- **F15（p.12）** 交错设定下构成变化。
  > the composition of units that contribute to an event-study coefficient will often change across different relative time periods.
- **F16（p.12）** 建议补充分队列结果均值图。
  > it will often be useful to supplement aggregated event-studies with plots of the time series of the mean outcome by adoption cohort.
- **F17（p.12）** 建议报告施加平衡性标准的聚合事件研究（紧接的 p.13 开头给出例子：仅保留处理前后至少各观察 3 期的单位）。
  > It may also be useful to report aggregated event-studies that enforce some balancing criteria
- **F18（p.10，脚注 9）** Callaway(2021) 的观点。
  > long-run violations of parallel trends are easier to visualize using the universal-base option
- **F19（p.12）** 检验与估计分开：用对称方法评估平行趋势合理性（此句在讨论 BJS 的语境中）。
  > for a method that treats the periods completely symmetrically (e.g. using the did package with the options described above) to visually evaluate the plausibility of the parallel trends assumption
- **F20（p.12）** 可直接对处理后估计做 Rambachan-Roth 敏感性分析（BJS 语境）。
  > One can also conduct sensitivity analysis for these post-treatment estimates directly using the approach in Rambachan and Roth (2023)
- **F21（p.8）** CS 公式只在 common timing 设定下给出（公式不手抄，锚点句：“Formally, in our setting with common treatment timing, we have that”）。
- **F22（p.7）** CS 的描述。
  > CS constructs event-studies by aggregating DiD comparisons of treated and not-yet-treated units.
- **F23（p.11）** Liu(2025) 的 block bias（队列层面的处理前违反度量）。
  > the pre-treatment violations of parallel trends for each adoption cohort (relative to a fixed comparison group) in a staggered setting

## 4. 推断（论文没有直接说）

- **I1**（基于 F4、F5、F21）你的默认 `att_gt + aggte("dynamic")` 图，处理前系数大概率是相邻期短差分，处理后是相对 t−1 的长差分。风险：论文推导仅限 common timing，外推到三批交错和你的 did 版本是推断（见 U4）。
- **I2**（基于 F9、F10、F13、F14）不能写“验证/有效”。推理：处理前部分只是“证据”；默认图的拐点/平坦模式可由平行趋势违反产生；仅看不显著有陷阱，还要看量级与置信区间。建议措辞“与平行趋势假设相容（consistent with），不构成验证”——这是我的写作建议，论文并未讨论措辞。
- **I3**（基于 F4、F6、F21）在论文的线性违反例子里，短差分的处理前系数是一条平坦线（等于每期斜率 γ，不是 0 时才是无趋势）。因此“平坦/接近 0”不等于“相对 t−1 的累积偏离很小”。可能出错处：该推读来自论文的匀速线性设定，其他形式未知。
- **I4**（基于 F1、F2、F3）改成 universal 后，你的处理前系数可能不再贴近 0，这正是其价值；交错设定下结果论文无法预判，需重跑。
- **I5**（基于 F15、F16、F17）样本构成算术（假设各批首年为 t=0，数据到 2024）：2022 批最多到 t+2，2020 批到 t+4，2017 批到 t+7。故 t+4 由 2017、2020 两批贡献，t+5 仅由 2017 批贡献，你的显著结果可能主要来自最早一批。这是我对你设定的计算，论文未分析你的数据。
- **I6**（基于 F11、F20、F1）HonestDiD 类分析不宜直接叠在默认（短差分）图上；我推断应先改 universal 再做，但论文未明说对 CS 如何实施，需核查。
- **I7**（基于 F22）论文模拟的对照组为从未处理组，与你一致，但 control group 选项（nevertreated / notyettreated）对结论的影响论文未讨论。
