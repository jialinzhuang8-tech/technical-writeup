# 阅读报告：Roth (2024/2026)《Interpreting Event-Studies from Recent DiD Methods》能否支持“平行趋势得到验证”

页码均为 PDF 页序，与论文打印页码一致(共 15 页)。

## 1. 一句话结论

**不能。(有条件结论，强度：中等)** 论文表明，did 包默认的事件研究图“处理前相邻期差分、处理后长差分”，处理前系数贴近 0 并不能证明平行趋势成立；论文建议改用 `base_period="universal"` 对称作图，并结合队列构成检查与敏感性分析汇报。论文仅在非交错设定下证明，对你的三批进入设定属推断。

## 3. 原文事实

- **F1 (p.2)**
  > the default event-study plots produced by software for several of the most popular recent methods should not be interpreted in the same way as traditional dynamic TWFE specifications

  含义：论文主旨，针对的是“评估平行趋势违反”这一用途。
- **F2 (p.2)**
  > there is no effect of the treatment but parallel trends is violated: the outcomes for the treated group are on an upwards linear trend relative to the comparison group

  含义：仿真 DGP——无处理效应、线性违反平行趋势。
- **F3 (p.3)**
  > the event-study plot produced by the R package for implementing the method of Callaway and Sant’Anna (2021, henceforth, CS) shows a clear kink at the treatment date

  含义：同一数据下 CS 图在处理时点出现拐点。
- **F4 (p.5)**
  > shows the results for the event-study generated by the CS method, using the default settings in the did package in R

  含义：Figure 1(b) 用的就是 did 包默认设置。
- **F5 (p.5)**
  > and then exhibits a kink at the time of the treatment, sloping upwards afterwards

  含义：同句前半为“相对平坦的处理前系数”(提取文本因断行连字符，脚本核验取了后半句)。Figure 1(b) 目视近似：处理前各期点估计约在 0–1 之间且置信区间多数覆盖 0(目视近似，p.4，未经文本核验)；处理后上升至约 4–5。
- **F6 (p.7)**
  > the pre-treatment coefficients are “short-differences”, i.e. comparisons of consecutive periods, whereas the post-treatment coefficients are “long-differences”

  含义：CS 默认构造的不对称(在非交错共同时点设定下展示)。
- **F7 (p.7)**
  > CS constructs event-studies by aggregating DiD comparisons of treated and not-yet-treated units

  含义：论文对 CS 的描述。
- **F8 (p.8)**
  > so the population version of the CS event-study coefficients show a kink at zero

  含义：仿真 DGP 下总体系数在 0 处有拐点。
- **F9 (p.8，公式)**：锚句 “we compare outcomes in consecutive periods”。含义：r<0 用相邻期 DID，r≥0 相对第 0 期；代入 DGP 后 r<0 恒为 γ，r≥0 为 γ(r+1)。公式请直接看原页。
- **F10 (p.9)**
  > a kink or jump in the plot may arise even if there is no treatment effect and parallel trends is equally violated in all periods

  含义：拐点/跳跃可能纯由构造产生。
- **F11 (p.9)**
  > One should therefore not apply the typical heuristics for visual inference

  含义：别用 TWFE 事件研究的视觉经验判断。
- **F12 (p.9)**
  > Sensitivity analyses that compare the pre-treatment and post-treatment coefficients from these event-studies

  含义：该句续写为“(如 Manski and Pepper, 2018; Rambachan and Roth, 2023)可能给出误导结论”，即在不对称构造下此类分析可能误导。
- **F13 (p.10)**
  > which is to use “long-differences” for the pre-treatment coefficients as well as the post-treatment coefficients

  含义：对 CS 的修正方案。
- **F14 (p.10)**
  > in the did R and csdid Stata packages using the options base_period = “universal” and long2

  含义：did 包里的具体选项。
- **F15 (p.10)**
  > Using these settings, the event-study estimates are numerically equivalent to the dynamic TWFE specification in the non-staggered setting considered here

  含义：等价性仅限非交错设定。
- **F16 (p.10，脚注 9)**
  > long-run violations of parallel trends are easier to visualize using the universal-base option, but argues that using short-differences may make it easier to detect violations of the no anticipation assumption

  含义：论文转述 Callaway (2021) 博客：两种基期各有用途。
- **F17 (p.12)**
  > report an event-study for a method that treats the periods completely symmetrically (e.g. using the did package with the options described above) to visually evaluate the plausibility of the parallel trends assumption

  含义：论文明确建议用 did + universal 画“检验平行趋势合理性”的图(该建议出现在 BJS 的讨论语境中)。
- **F18 (p.12)**
  > One can also conduct sensitivity analysis for these post-treatment estimates directly using the approach in Rambachan and Roth (2023)

  含义：此处“post-treatment estimates”指 BJS 的处理后估计；并指向 Liu (2025) 谈交错设定的实现。
- **F19 (p.12)**
  > does not threaten the validity of the post-treatment event-study estimates for recent methods if the appropriate parallel trends assumption holds

  含义：处理后估计仍可解释，但前提是相应平行趋势成立。
- **F20 (p.12)**
  > complications may arise when interpreting these results in staggered settings

  含义：交错设定另有复杂性。
- **F21 (p.12)**
  > composition of units that contribute to an event-study coefficient will often change across different relative time periods

  含义：交错下各相对时间系数的单位构成不同(论文引 Liu 2025)。
- **F22 (p.12)**
  > it will often be useful to supplement aggregated event-studies with plots of the time series of the mean outcome by adoption cohort

  含义：补画分队列均值时间序列图。
- **F23 (p.12)** / **F24 (p.13，跨页)**
  > enforce some balancing criteria
  
  > to units who are observed at least 3 periods before and after treatment

  含义：报告平衡化的事件研究，例如只保留处理前后至少各观测 3 期的单位。
- **F25 (p.12，脚注 14)**
  > researchers should ideally also look at the magnitudes of the pre-trends estimates and their confidence intervals

  含义：看处理前估计的量级与置信区间，而非只看显著性。
- **F26 (p.3)**
  > Figure 1 shows event-studies for a single simulation draw from this DGP when there are 100 total units and half of them are treated

  含义：证据规模仅为一次仿真。
- **F27 (p.3)**
  > a simulation of an extremely simple non-staggered DiD setting

  含义：设定是极简非交错 DID。

## 4. 推断

- **I1 (基于 F2, F5, F6, F9, F10)**：默认设置下，处理前系数贴近 0 不能单独支持“平行趋势得到验证、DID 设定有效”。论文的例子里，平行趋势被明显违反，默认图的处理前系数却仍相对平坦；原因是相邻期差分只显示每期常数 γ，累积漂移到处理后才显现。论文没有评价这句措辞，也没有分析你的数据。可能出错：你的数据里违反形式未知(U5)。
- **I2 (基于 F4, F6, F13, F14)**：你很可能处于“处理前短差分、处理后长差分”的不对称构造，应以 `base_period="universal"` 重跑对照。论文没写 did 默认值的变量名，需核对版本(U1)。
- **I3 (基于 F6, F20, F27)**：论文推导只在非交错设定；你是三批交错进入。不对称来自基期选取，推断机制同样存在，但论文未在交错设定下证明或仿真。
- **I4 (基于 F21, F22, F24；含我的算术)**：按 2010–2024 与进入年份，设 r=0 为进入当年，2017 队列最多观察到 t+7、2020 最多 t+4、2022 最多 t+2。则 t+5 只可能来自 2017 队列，t+4 来自 2017 与 2020 队列，而处理前 4 期三个队列都有。因此图左右两侧的单位构成不同，需分队列检查。这不是论文原文。
- **I5 (基于 F19, F12, F18)**：t+4、t+5 显著只在平行趋势成立时才能解释为处理效应，而你尚未做敏感性分析。论文提示在不对称图上做前后比较的敏感性分析可能误导，所以应先基于对称(universal)构造；对 CS 在交错下的具体做法论文未写(U4)。
- **I6 (基于 F15, F20)**：改用 universal 后，论文只保证非交错下与 TWFE 数值等价；对交错设定不能宣称“等价于 TWFE 事件研究”，也不应把 TWFE 的视觉经验直接套用。
