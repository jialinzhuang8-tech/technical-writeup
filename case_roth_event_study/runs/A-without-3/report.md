# 阅读报告：默认 CS 事件研究图的"平行趋势验证"能写吗？

论文：Roth (2026), *Interpreting Event-Studies from Recent DiD Methods*, arXiv:2401.12309v2（共 15 页，下文页码 = PDF 页码 = 论文页脚页码）。

## 1. 结论（直接回答）

**不能**据"默认设置下处理前 4 期系数贴近 0"写"平行趋势假设得到验证、DID 设定有效"。

论文给出的论据：用 R `did` 默认设置画出的 CS 事件研究图，其处理前系数和处理后系数的构造方式不对称，因此"处理前贴近 0"不能当作平行趋势成立的证据，也不能用传统 TWFE 事件研究图的目测方法来读。

论文建议的做法（见第 5 节）：
1. 把 CS 的 base period 改为 universal，使处理前、后系数对称，重新画图。
2. 用 universal 版本的图来评估平行趋势是否可信。
3. 额外报告各 cohort 的样本构成和各 cohort 的结果均值时间序列。
4. 敏感性分析（HonestDiD 一类）只在对称构造的系数上做。

措辞上应改为"未发现明显的处理前差异，但……"，并交代局限（见第 6 节）。

## 3. 推断（论文没有直接说，是我从论文推出的）

1. **论文的实证内容仅限非交错设定。**
   - 模拟和公式都是单一处理时点（p.3, p.7–8）。
   - 用户是 2017/2020/2022 三批进入的交错设定。
   - 论文说明了"默认 CS 处理前系数为短差分"这一构造（p.7）。我推断它在交错情形同样适用，但这一点论文没有在交错设定下单独验证。
   - 论文的数值等价结论（p.10）也只对非交错情形声明。
2. **用户的 t+4、t+5 显著结果在该论文框架下可能含有趋势违背的成分。**
   - 在论文模拟里，处理前系数平坦、处理后系数递增，可以完全由线性趋势违背产生（p.3–4）。
   - 用户的图形态（处理前近 0、处理后逐期变大）与这种情形相似，但这不等于用户数据存在这个问题。只能说"不能排除"。
3. **用户的 cohort 构成使 t+4、t+5 的样本构成很不均衡。**（根据任务设定的年份 2010–2024 和三批进入年份计算）
   - 2017 批：t+0…t+7，处理前最多 7 期。
   - 2020 批：t+0…t+4。
   - 2022 批：t+0…t+2，处理前最多 12 期。
   - 所以 t+5 只来自 2017 批；t+4 只来自 2017 和 2020 两批；2022 批对 t+3 及以后没有贡献。
   - 这正是论文 p.12 所说的"各相对期样本构成不同"问题，用户目前没有汇报。
   - 这是按年份推算的结果，实际还取决于各批的企业数量和样本是否有缺失。
4. **在默认图上直接做 HonestDiD 不合适。** 论文 p.9 提示，在不对称构造的系数上做比较处理前后系数的敏感性分析可能误导。我据此推断：应先用 universal 基期的结果来做。
5. **建议同时保留两种基期的图（推断）。** 论文引用 Callaway 的观点（p.10 脚注 9）：universal 更适合看长期趋势违背，varying 更适合看预期效应。论文本身没有明确要求两个都报告。

## 4. 论文没有覆盖的内容

- 没有讨论交错处理下 `did` 的具体参数（如 `control_group`、`balance_e`、`anticipation`）的选择，也没有给出这些参数对结果的影响。（`balance_e` 等是我对 R 包参数的了解，论文外信息，使用前请自行核对文档。）
- 没有给出交错 CS 配合 HonestDiD 的具体操作步骤；只在 p.11–12 提到 Liu (2025) 讨论了与插补类估计量结合的做法。
- 没有给出论文中"平行趋势得到验证"这类措辞的标准写法；也没有讨论统计功效、处理前检验后的选择偏误（只引用了 Roth 2022，p.11–12 脚注 14）。
- 没有金融/A 股场景的内容；没有讨论样本量大（数千家对照企业）时置信区间变窄的影响。
- 没有说明用户的"处理前 4 期"是否足够；论文只在 p.12 提到平衡化窗口的例子（处理前后各至少 3 期）。
- 论文是技术性说明（note），没有真实数据的实证检验；所有数值证据来自单次模拟抽样（p.3）。

## 5. 后续动作（按优先级）

1. **重画图。** 把 `att_gt(..., base_period = "universal")` 后的 `aggte(type = "dynamic")` 图作为平行趋势评估用图（p.10）。注意 universal 下处理前一期（t-1）系数恒为 0，是基准，不能当作"检验通过"的证据。（这一点是 universal 基期的性质，论文 p.10 的"基期固定为处理前一期"隐含了它；我的表述属于对该性质的补充说明。）
2. **同时保留默认图（varying）。** 作为对 no-anticipation 的检查，并在文中说明两种图的差别（p.10 脚注 9，推断）。
3. **报告各 cohort 构成。** 列出 2017/2020/2022 各批的企业数、可观测的事件期范围；画各批的结果均值时间序列（p.12）。
4. **做平衡化的事件研究。** 例如限制在事件窗口内各批都能观测到的期数，或像论文例子那样只保留处理前后各至少 3 期的单位（p.12–13）；检查 t+4、t+5 是否仍显著。注意 2022 批只有 t+0…t+2，所以窗口取到 t+4/t+5 时会把它排除出去，应明确说明。
5. **做敏感性分析。** 在 universal 基期的结果上做 HonestDiD（Rambachan–Roth），报告处理后效应在多大的趋势违背幅度内仍显著（p.9, p.12）。
6. **看大小和置信区间，不只看显著性。** 处理前系数的置信区间是否排除了足以解释处理后效应的趋势（p.11–12 脚注 14）。

## 6. 论文写作建议措辞（推断，不是论文原文）

> 事件研究图中处理前系数在统计上与零无显著差异，未发现明显的预趋势。但由于处理前系数的置信区间较宽且该检验不能证明平行趋势成立，我们进一步采用统一基期（universal base period）重新估计，并用 Rambachan and Roth (2023) 的方法检验结论对平行趋势违背的稳健程度。

避免写："平行趋势得到验证""DID 设定有效"。
